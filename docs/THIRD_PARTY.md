# Komponen pihak ketiga

Source aplikasi ini menggunakan komponen berikut. Simpan pemberitahuan lisensi dependency saat mendistribusikan ulang aplikasi. Lockfile mengunci versi transitive yang dipakai build; berkas LICENSE upstream tetap menjadi sumber yang mengikat.

| Komponen | Sumber |
| --- | --- |
| React / React DOM | https://github.com/facebook/react |
| Vite | https://github.com/vitejs/vite |
| Transformers.js | https://github.com/huggingface/transformers.js |
| ONNX Runtime | https://github.com/microsoft/onnxruntime |
| Whisper Tiny ONNX | https://huggingface.co/onnx-community/whisper-tiny |
| Whisper Base ONNX | https://huggingface.co/onnx-community/whisper-base |
| Lucide icons | https://lucide.dev/license |
| DM Sans / Manrope | https://fontsource.org |
| Zod | https://github.com/colinhacks/zod |
| Vitest | https://github.com/vitest-dev/vitest |
| Testing Library | https://testing-library.com |

Bobot model tidak disertakan dalam ZIP source; browser mengunduh revisi model yang dipin. Aplikasi tidak menggunakan logo BINUS ataupun mengklaim sebagai aplikasi resmi kampus.
